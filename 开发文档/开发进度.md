## 关键决策（已定，别再讨论）

- **单账号模式**。`FeiniuSourceConfig` 不带凭证也不带 `accountId`，
  只有 `id`/`name`/`enabled`。凭证仍归 `AccountStore` + `AppFnConnectionSettings`。
- **默认飞牛音源 ID = `'feiniu-default'`**。存量行 `sourceId` 保持 NULL，
  由 `effectiveSourceId` 映射，**无需回填脚本**。
- **本地歌 ID = 规范化绝对路径**（跟上游一致）。跨扫描稳定，收藏/歌单存活。
- **歌手/专辑 guid 用名字派生**（`local-artist:<名字>`），保证聚合并避免与飞牛撞车。
- **歌手名不拆分**。按 `/` 拆会把 `AC/DC` 拆成两个歌手。
- **移除音源只删配置，不删歌曲行**。
- **文件消失只标记失效，不删行**（避免悬空引用）。
- **封面沿用 `covers_v2/<sha1>.img` 命名** —— 车机/Android Auto 零改动即可读本地图。

## 功能移除：FnMusicEnhance 依赖链（2026-09-18）

用户决策：整套移除依赖 `FnMusicEnhance` 服务端增强（NAS 伴生服务）的功能链
（用户的 NAS 未安装该容器，也不打算安装；相关 UI 此前对这类用户是死入口）。

- **删除页面**：元数据管理 / 匹配设置 / 数据源维护 / 批量匹配 / 歌手专辑编辑 /
  NAS 文件夹浏览（`pages/library/folders_page.dart`）/ `library_metadata.dart`
- **删除服务**：`services/song_match/`（5 文件）、`services/companion/`（3 文件）、
  `services/lyrics/lyric_companion_service.dart`、`services/feiniu/folder_models.dart`、
  `utils/map_concurrent.dart`（仅匹配并发在用）
- **删除状态**：`state/settings_match.dart` / `settings_lyric_companion.dart` /
  `settings_lyric_auto_search.dart`
- **删除 UI 入口**：设置页「元数据管理」；歌曲编辑页「匹配歌曲信息 / 联网搜索封面 /
  匹配设置 / 歌词编辑区」；歌曲页「文件夹」入口；歌手/专辑详情页「编辑」按钮及
  `onMetadataChanged` 回调链；多选「批量匹配」；歌单页「导入歌单」；播放无歌词
  自动搜索（`lyrics_service`）；`main.dart` 对应启动加载
- **行为变化**：歌曲编辑页保存时，专辑名被改过才精确匹配已有专辑取 guid（原来会
  经服务端增强自动新建实体）；匹配不到不传 albumGUID，由飞牛服务端自行处理
- **删除测试**：6 个（match / 插件解析 / 打分 / 并发 / library_metadata）
- **不受影响**：飞牛主 API 全部功能、播放/歌词展示（`getLyricText` 原接口）、
  音源多源化重构（`services/source/`）、本地封面上传（`uploadTrackCover` 主 API）
