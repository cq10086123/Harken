# 可选：发布产物改名工作流补丁（需 workflows 权限）

沙箱的 GitHub App 无 `workflows` 权限，无法推送 `.github/workflows/` 改动，
因此以下改名**需你自行应用**（应用前后 CI 均可用；应用后发布产物名才与品牌一致）。

```diff
--- a/.github/workflows/build-release.yml
+++ b/.github/workflows/build-release.yml
@@
-          Copy-Item -Path build/installer/FeiNiuMusic-v*-Windows.zip -Destination . -Force
+          Copy-Item -Path build/installer/Harken-v*-Windows.zip -Destination . -Force
@@
-            FeiNiuMusic-v*-Windows.zip
+            Harken-v*-Windows.zip
@@
-             FeiNiuMusic-v${VERSION}-Android-arm64-v8a.apk
-             FeiNiuMusic-v${VERSION}-Android-armeabi-v7a.apk
-             FeiNiuMusic-v${VERSION}-Android-x86_64.apk
+             Harken-v${VERSION}-Android-arm64-v8a.apk
+             Harken-v${VERSION}-Android-armeabi-v7a.apk
+             Harken-v${VERSION}-Android-x86_64.apk
@@
-             FeiNiuMusic-v${VERSION}-Android-z-luna-arm64-v8a.apk
+             Harken-v${VERSION}-Android-z-luna-arm64-v8a.apk
@@
-            FeiNiuMusic-v*.apk
+            Harken-v*.apk
@@
-          ditto -c -k --sequesterRsrc --keepParent "飞牛音乐.app" \
-            "${GITHUB_WORKSPACE}/FeiNiuMusic-v${VERSION}-MacOS.zip"
+          APP=$(ls -d build/macos/Build/Products/Release/*.app | head -n1)
+          ditto -c -k --sequesterRsrc --keepParent "$APP" \
+            "${GITHUB_WORKSPACE}/Harken-v${VERSION}-MacOS.zip"
@@
-          cp -R "飞牛音乐.app" "$STAGE/"
+          cp -R "$APP" "$STAGE/"
@@
-          hdiutil create -volname "FeiNiuMusic" -srcfolder "$STAGE" \
+          hdiutil create -volname "Harken" -srcfolder "$STAGE" \
             -ov -format UDZO \
-            "${GITHUB_WORKSPACE}/FeiNiuMusic-v${VERSION}-MacOS.dmg"
+            "${GITHUB_WORKSPACE}/Harken-v${VERSION}-MacOS.dmg"
@@
-            FeiNiuMusic-v*-MacOS.zip
-            FeiNiuMusic-v*-MacOS.dmg
+            Harken-v*-MacOS.zip
+            Harken-v*-MacOS.dmg
@@
-            "${GITHUB_WORKSPACE}/FeiNiuMusic-v${VERSION}-iOS-unsigned.ipa"
+            "${GITHUB_WORKSPACE}/Harken-v${VERSION}-iOS-unsigned.ipa"
@@
-          path: FeiNiuMusic-v*-iOS-unsigned.ipa
+          path: Harken-v*-iOS-unsigned.ipa
@@
-            android-artifact/FeiNiuMusic-v*.apk
-            windows-artifact/FeiNiuMusic-v*-Windows.zip
-            macos-artifact/FeiNiuMusic-v*-MacOS.dmg
-            macos-artifact/FeiNiuMusic-v*-MacOS.zip
-            ios-artifact/FeiNiuMusic-v*-iOS-unsigned.ipa
+            android-artifact/Harken-v*.apk
+            windows-artifact/Harken-v*-Windows.zip
+            macos-artifact/Harken-v*-MacOS.dmg
+            macos-artifact/Harken-v*-MacOS.zip
+            ios-artifact/Harken-v*-iOS-unsigned.ipa
```

应用后还需同步两处（否则产物名对不上）：
1. `scripts/package_windows.ps1`：`$BundleName = "Harken-v$Version-Windows"`，并删除上方 CI 兼容注释。
2. `macos/Runner/Configs/AppInfo.xcconfig`：`PRODUCT_NAME = Harken`，
   并把 `macos/Runner/Info.plist` 的 `CFBundleName` 改回 `$(PRODUCT_NAME)`（可保留字面值，无副作用）。

上面 macOS 那段改用 `$APP=$(ls -d ...)` 取实际产物，之后再改 PRODUCT_NAME 也不会再断链。
